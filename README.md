# SENTINEL Clipboard Firewall

Herramienta local y open source para inspeccionar información técnica
antes de compartirla y analizar comandos potencialmente peligrosos.

## Funciones previstas

- Detectar secretos y datos de infraestructura.
- Sanitizar texto mediante etiquetas consistentes.
- Analizar comandos Bash y PowerShell sin ejecutarlos.
- Integrarse con el portapapeles mediante acciones explícitas.

## Principios de seguridad

- El análisis funciona sin conexión a Internet.
- Los comandos analizados se tratan como datos y nunca se ejecutan.
- El contenido original no se registra ni persiste por defecto.
- Los ejemplos y las pruebas utilizan exclusivamente datos sintéticos.
